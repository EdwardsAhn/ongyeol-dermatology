# 하로레피부과 랜딩페이지

하로레피부과의 진료 분야, 진료 방식, 내원 안내와 자주 묻는 질문을 소개하는 반응형 정적 웹사이트 시안입니다. 병원명, 주소, 진료 시간, 전화번호와 예약 채널은 실제 정보에 맞게 입력해야 합니다.

## 실행 방법

별도 빌드나 의존성 설치 없이 `index.html`을 브라우저에서 열면 됩니다.

로컬 HTTP 서버로 확인하려면 프로젝트 폴더에서 다음 명령을 실행하세요.

```sh
python3 -m http.server 8000
```

그다음 브라우저에서 <http://localhost:8000>을 엽니다. 종료할 때는 터미널에서 `Ctrl+C`를 누릅니다.

## 파일

- `index.html`: 페이지 구조, 스타일, 모바일 내비게이션과 FAQ를 포함한 단일 페이지
- `.openai/hosting.json`: Sites 프로젝트 메타데이터. 저장소에는 포함하지 않습니다.

## 참고

페이지의 연락처와 진료 정보는 교체용 문구입니다. 게시 전에 병원의 확인된 정보로 업데이트하세요. 글꼴은 Google Fonts에서 불러오며, 연결할 수 없을 때는 시스템 글꼴을 사용합니다.
